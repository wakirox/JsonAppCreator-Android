Describe an app in a JSON file, open it in JSON App Creator, and use it as a native Android app. No Android Studio, no build, nothing to compile.

WHAT YOU CAN BUILD
• Screens with vertical and horizontal layouts, text, buttons and images from the web
• Lists, written in the file or loaded from a REST API, with a detail screen for each item
• Forms with text, number, email, password, date, selector and checkbox fields
• Navigation between screens, alerts, and actions on tap or long press
• GET and POST requests, with the response shown on the next screen
• Data binding with dot paths and ${placeholders}

WRITE IT YOURSELF, OR ASK AN AI
The format is documented field by field, with a JSON Schema and a guide written for AI assistants: describe the app you want, save the answer as a .json file, and open it.

CHECKED BEFORE IT RUNS
The whole file is validated before it opens. A mistake is shown with its exact place, like $.mainView.views[1].type, and the last working app stays loaded.

READY-MADE EXAMPLES
The menu opens example apps to start from: a simple app, a form, and two catalogues loaded from public APIs. View the JSON behind any of them, change it, and load your own version.

YOUR API KEYS STAY ON YOUR PHONE
If an app needs an API key, JSON App Creator asks for it once and keeps it encrypted on your phone, tied to that file. It is never written into the JSON.

OPEN FILES FROM ANYWHERE
Open a .json file from your file manager, downloads or a chat, and JSON App Creator runs it.

OPEN SOURCE, NO ACCOUNT
No ads, no account, no data collected. JSON App Creator is open source under the MIT licence; the format reference and examples are on GitHub: github.com/wakirox/JsonAppCreator-Android
